## Dataset

### Linear Regression
- Dataset: California Housing Dataset
- Sumber: https://scikit-learn.org/stable/datasets/real_world.html#california-housing-dataset
- Tujuan: memprediksi nilai median rumah berdasarkan karakteristik wilayah di California.

### Logistic Regression
- Dataset: Breast Cancer Wisconsin Diagnostic
- Sumber: https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic
- Tujuan: mengklasifikasikan tumor menjadi *malignant* atau *benign*.

## Ringkasan Hasil

### Linear Regression

Model Linear Regression digunakan untuk memprediksi nilai median rumah pada California Housing Dataset. Evaluasi pada data uji menghasilkan MAE sebesar 0.5425, MSE sebesar 0.5473, RMSE sebesar 0.7398, dan R-squared sebesar 0.5823. Perbedaan hasil data latih dan data uji tidak terlalu besar, sehingga model tidak menunjukkan indikasi overfitting yang kuat.

### Logistic Regression

Model Logistic Regression digunakan untuk mengklasifikasikan diagnosis tumor menjadi *malignant* atau *benign* pada Breast Cancer Wisconsin Diagnostic Dataset. Model memperoleh accuracy sebesar 0.9123, precision sebesar 0.9697, recall sebesar 0.8889, dan F1-score sebesar 0.9275. Hasil tersebut menunjukkan bahwa model memiliki performa klasifikasi yang baik.
